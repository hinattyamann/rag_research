# 原稿掲載用の図表

掲載用に編集した図表をこのフォルダへ保存する。
解析・元図の正本は [固定v23の成果](../../../reports/fixed_v23_order_study_v1/) に保持し、上書きしない。
2026年11月5日の初稿1では、experimental_design_en/ja（実験設計図）とorder_increment_en/ja（主要増分図）をPNG/SVGで保存した。
両版の説明は同じ内容で、図番号はそれぞれ図1/図2。Wordには85 mm幅のPNGを配置し、SVGも編集・再利用用に保持する。
2026年11月6日の初稿2では、文字サイズと配置幅を保って図内の縦余白を整理した。
生成時の図寸法は設計図3.35×3.0インチ、主要増分図3.35×1.9インチで、両言語のWord描画で判読性を確認した。
元集計・区間・研究用の図表は変更していない。
主要増分図は元のprimary_comparison.csvを掲載向けに再描画し、区間を再計算していない。
実験設計図は既存Protocol/固定設定の処理関係を示す。実データの具体例や追加実験の結果を表す図ではない。
生成処理は [原稿生成ツール](../manuscript/build_draft.py)、数値照合は [初稿の到達点](../notes/draft_status.md)を参照。

Wordへ配置する図は、元解析のManifest・Hash・Commitと、掲載版のファイル名を対応付ける。
1段幅85 mmに縮小した後の文字・誤差区間・凡例の判読性を確認し、必要なら図を分割して描き直す。
元の大型グラフを単に縮めて全て掲載することを前提にしない。
図のキャプションは下、表のキャプションは上に置く。

追加検証の図表は集合名と版を分け、既存Main/Calの図表を未記録のまま置き換えない。
