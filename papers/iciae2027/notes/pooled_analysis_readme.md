# 200問の事後統合集計

2026年11月10日。ユーザーとの対話で、Main・Cal・Extという内部名称による説明をやめ、固定評価器による200問の評価実験として原稿全体を改稿することが決まった。このため、以下の新しい統合集計を行う。既存の収集・採点・解析とその区間は変更しない。

## 集計前に定めた方法

- 対象は保存済みの英語100問・日本語100問。既存80問と追加120問を収集前から一括計画していたとは扱わない。原稿の統計は結果確認後に作る事後統合である。
- 主指標は元の定義を使い、各質問の順序群の判断不一致率Oから同順序反復群の判断不一致率Rを引く。canonical trial_planで一意な順序を確定し、全必要試行が有効な質問だけを用いる。除外と未知ラベルを0へ補完しない。
- 言語内の比較可能質問を等重みで集計する。文書グループ単位の復元抽出を10,000回、Seed42、en/ja順の独立子乱数で行う。2.5/97.5パーセンタイルの区間と、同じ反復番号の日本語平均−英語平均の区間を計算する。保存順ではなく文書グループID・質問IDで整列する。質問の独立性をモデル呼出しや文へ拡張しない。
- 区間は今回の比較可能標本と固定構成に条件付きの記述であり、異なる収集時期・元分割の混合を解消しない。文書グループの非重複と主要科学的条件の一致を確認する。分析は旧主解析の事前登録を置き換えず、論文に事後統合と明記する。
- 全選定問の方策品質・欠測・判定不能と費用、既知二値A/B遷移における改善見逃しと有害選択、比較可能問内の順序による選択Y変化、外部AI期待判定との意味不一致、既定5閾値の点推定を集計する。費用は原記録の既知分を使い、中断要求の不明費用を補わない。
- 推論・再採点・対象追加・閾値調整は行わない。元資料・旧集計は保持し、新しい派生結果を別ファイルに保存する。

## 再現

`manuscript/derive_pooled_results.py`が元200問の保存入力、試行計画、判断、選択回答・ラベルと方策CSVを照合し、`pooled_results_v1.json`を生成する。旧80問と追加3バッチの既存照合処理も利用する。

```powershell
uv run python papers/iciae2027/manuscript/derive_pooled_results.py
uv run python papers/iciae2027/manuscript/derive_pooled_results.py --check
```

原稿では内部の収集区分をデータ群名として用いない。監査用の内部来歴は派生JSONと元資料で追跡できるよう残す。
