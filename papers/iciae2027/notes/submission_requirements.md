2026年11月20日に提出するのは、査読を受けるための **英語フルペーパーPDF** である。
要旨のみの提出と、採択後の最終原稿提出を区別する。

以下では、公式掲載の条件、本プロジェクトの作業方針、未確認事項を分けて記録する。

## テンプレートの書式

S2の本文指示とOOXML設定を照合した。本文編集では公式テンプレートの段落・セクションを保持する。
文字サイズや行間を縮めてページ内へ押し込むことは、テンプレートで禁止されている。

| 項目 | 確認した指定・設定 |
|---|---|
| 用紙 | A4。XMLの用紙サイズは11906×16838 twip、A4指定 |
| 余白 | 上下25 mm、左右16 mm |
| 段組 | タイトル・著者欄の後は2段。段幅85 mm、段間8 mm |
| タイトル | 16 pt、太字、中央揃え |
| 著者・所属 | 10.5 pt。全著者の所属と責任著者のメールアドレスを記載 |
| Abstract | 必須、**300語未満**、本文はTimes New Roman 10 pt。左段の先頭 |
| Keywords | **3～5語**、カンマ区切り、Abstractの下 |
| 本文 | Times New Roman 10 pt、両端揃え。ダブルスペースにしない |
| 章見出し | Times New Roman 12 pt、太字、段内中央揃え |
| 節見出し | Times New Roman 10 pt、太字、左揃え |
| 図・写真 | 連番と下側のキャプション。縮小後も判読できる画像を使用 |
| 表 | 連番と上側のキャプション |
| 図表の位置 | 段の上端・下端への配置指示に従う。2段幅図の扱いは最終レイアウト時に原文を再確認 |
| 数式 | 通し番号を付ける |
| References | 本文での出現順。本文中は丸括弧付き番号の上付き表記 |
| Acknowledgment | 必要な場合のみ記載 |

タイトル・著者欄が1段、その後が2段であることをXMLの2つのセクションで確認した。
XMLでは余白が丸められたtwip値となっているため、同等の数値へ独自に作り替えるより原本を維持する。
一般的なIEEEテンプレートの用紙や引用形式を、このテンプレートへ持ち込まない。

## 投稿システムで必要な情報

[ICIAE2027 Submission System](https://www2.ia-engineers.org/conference/index.php/iciae/iciae2027/index)を使用する。
S1には、新規アカウントの作成、ログイン後のUSER HOMEからNew Submission、他のIIAE会議アカウントの登録案内がある。

S4の公開チェックリストには、次の事項がある。

- 提出ファイルがPDFである。
- ICIAE2027主催者のテンプレートで準備されている。
- 本文のURLがクリック可能である。
- 著者要領の書式・文献記載に従っている。
- **全著者の情報を投稿システムへ登録する。**

テンプレートは著者名・所属・責任著者連絡先を含む。
今回確認した公開資料には、著者情報を削除する二重盲検査読の指示は見当たらなかった。
査読方式を断定せず、投稿画面の追加指示を提出前に照合する。
今回はアカウント作成・ログイン・投稿を実施していない。

## 独創性と採択後の条件

S2は未発表の独自研究を求め、他の会議・雑誌で審査中の論文を受け付けないとしている。
S2/S4は著者の権利保持とCC BY 3.0による公開を説明している。
投稿時の同意文と、原稿に含める第三者図表・データ等の表示を提出前に照合する。

S3/S5では、採択論文の予稿集掲載には少なくとも1名の著者の期限内登録が条件となる。
推薦先ジャーナルへの掲載は別の査読・修正を経るもので、会議採択だけで保証されない。

S6/S7の早期登録の区切りは **2027年1月8日まで**、通常登録は1月9日から。
日本在住者向けの学生参加費は早期 **28,000円**、通常 **42,000円**。
1件の発表につき最低1名の著者の事前支払いが必要で、支払い後は返金しないとの記載がある。
これは参加登録の条件であり、11月20日の初回投稿時に支払い済みである必要があると確認した意味ではない。
支払い・参加形態の選択は今回行っていない。
