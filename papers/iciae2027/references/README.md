# 引用文献と照合資料

原稿に引用する文献の書誌、DOI/公式URL、読んだ版、確認日、引用する主張と原文箇所を管理する。
既存の [関連研究の整理](../../../docs/related_research_positioning.md) は調査の出発点であり、
書誌・本文・採録状況を未確認のまま原稿へ転記しない。

Word本文の引用は公式テンプレートの上付き丸括弧番号と出現順にそろえる。
文献PDF全文は、再配布条件を確認せず公開Repositoryへ追加しない。
初稿1には10件の参考文献を収録し、[出典確認記録](source_review.md)に使用箇所と確認範囲を記した。
書誌・URLは日英共通で、著者名と文献題名は原書誌のまま保持する。
網羅的な文献調査や全原典の精読が完了した意味ではなく、引用と位置付けの最終確認は継続する。
